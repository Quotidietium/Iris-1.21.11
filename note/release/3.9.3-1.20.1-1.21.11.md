# Iris 3.9.3-1.20.1-1.21.11 性能优化版

**日期**：2026-08-22 · **分支**：`perf/optimization`（自 `901c7d659`）
**红线承诺**：全部改动经 20 个基准场景的固定种子摘要（golden）逐位比对 + 3D 适配器 60 万采样 A/B 对照，**地形生成与用户交互行为零变化**。

## 三轮优化总览

### 第 1 轮 · CPU 热点（`ca6f701e3`）
- CNG 噪声内核定参重载（`noise/fit/fitDouble`），消除每采样 varargs 数组；移除无读者的静态计数器递增
- `IrisInterpolation.getNoise`：每调用 HashMap+装箱 → 线程内原始类型备忘表（嵌套安全）
- `IrisComplex.interpolateGenerators`：hi/lo 双遍采样合并为单遍（高度流采样量减半）
- `IrisComplex.implode`：子群系稀有度映射表按群系缓存——**选择 2585→227 ns（11.4×），0 分配**
- `IRare` 稀有度挑选预计算权重表（同除法顺序，位级一致）

### 第 2 轮 · 内存/分配（`e52705c42`）
- `ChunkCache2D` 惰性 Entry（原每流每区块预分配 256 个 Entry ≈ 6KB）
- `WorldCache2D` 区块键 Long 装箱单槽备忘（volatile 原子发布）
- 2D/3D 插值捕获 lambda → 可复用适配器（3D 路径 **0 B/op**，`bench.Verify3D` 60 万采样 A/B 零差异）
- `interpolateGenerators` 原始类型对缓存
- **单线程场景分配合计 -75.2%**；主要噪声路径全部 0 B/op

### 第 3 轮 · 并发/共享缓存（`94809ea86`）
- `MultiBurst` 空闲时间戳从 AtomicLong RMW 降为 volatile 写（每 Stage 数百次 burst 不再争用缓存行）
- `BurstExecutor`/`sync` 去掉每批次列表拷贝
- `AtomicCache` 快路径单次 volatile 读
- `implode` 的 `setInferredType` 条件写（消除多线程同值写风暴）
- `WorldCache2D` CLHM → Caffeine：生产 raster 模式 8 线程 **1.54×**，聚合扩展 2.3×→3.6×
- 新增并行基准：par-cng **~7× 扩展**（证明 CNG 已无共享可变状态）

## 基准与验证设施（`benchmark/`）

- 独立 javac 基准（真实 core 源码 + 13 个最小 stub），兼作**全量编译校验**（Gradle 不可用时）
- 20 个场景（14 单线程 + 3 并行 + 3 追加），CSV 结果入库 `benchmark/results/`
- `verify.sh` 金样本比对 + `bench.Verify3D` 等价性证明
- 详细报告：`note/report/perf/round0-baseline.md` ~ `round3-concurrency.md`
